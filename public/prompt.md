[역할 정의]
너는 UI/UX 디자인 감각이 뛰어난 전문 웹 프론트엔드 개발자야. 
개발을 처음 해보는 초보자인 나를 위해, HTML, CSS, JavaScript를 한 파일(index.html) 또는 관리하기 쉬운 구조로 완벽한 전체 코드를 작성해 줘. 

[프로젝트 개요]
- 서비스명: 취준생과 직장인을 위한 감성 자기관리 투두리스트
- 디자인 콘셉트: 핀터레스트 스타일의 미니멀하고 따뜻한 파스텔톤 (베이지, 연한 그린, 부드러운 그레이 활용), 넓은 여백, 둥근 모서리(border-radius), 깔끔한 폰트 사용.

[화면 구조 및 기능 요구사항]
전체 화면을 가로로 이등분한 Split-Screen 레이아웃으로 구현해 줘.

1. 왼쪽 영역: 월별 달력 (Monthly Calendar)
- 상단에 현재 '연도와 월'이 표시되고, 이전 달/다음 달로 이동할 수 있는 화살표 버튼이 있어야 해.
- 일요일부터 토요일까지 정갈하게 정렬된 월별 달력 화면이 필요해.
- '오늘 날짜'는 시각적으로 특별하게 하이라이트(예: 연한 배경이나 테두리) 해줘.
- 특정 날짜를 클릭하면 해당 날짜가 '선택됨' 상태로 스타일이 바뀌어야 해.

2. 오른쪽 영역: 투두리스트 관리 (Todo List)
- 왼쪽 달력에서 [선택한 날짜]가 상단 타이틀로 표시되어야 해. (기본값은 '오늘 날짜')
- 날짜를 클릭할 때마다 해당 날짜에 저장된 투두리스트만 우측에 업데이트되어 나타나야 해.
- 기능: 
  ① 할 일 입력창과 [추가] 버튼
  ② 할 일을 완료하면 취소선이 그어지는 체크박스 기능
  ③ 할 일 삭제(X) 버튼
  ④ 태그 선택 기능: 할 일을 등록할 때 [💼 취업/업무], [🏡 일상], [📚 자기계발] 중 하나를 선택할 수 있게 해주고, 등록된 할 일 옆에 예쁜 컬러 배지로 표시해 줘.
- 상단 또는 하단에 해당 날짜의 투두 달성률을 보여주는 예쁜 '프로그레스 바(Progress Bar)'를 넣어줘.

3. 데이터 저장
- 새로고침을 해도 내가 작성한 할 일 데이터가 사라지지 않도록 브라우저의 'LocalStorage'를 사용해 날짜별로 데이터를 저장하고 불러오도록 구현해 줘.

[출력 요구사항]
초보자도 바로 실행해 볼 수 있도록 HTML, CSS(Tailwind CSS CDN 활용 추천), JavaScript 코드를 생략 없이 '전체 코드'로 제공해 줘. 각 핵심 기능마다 주석을 친절하게 달아줘.
